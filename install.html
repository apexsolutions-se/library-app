Library Borrow & Return

A simple library system for borrowing and returning books using student cards.

Install Library App

Open this page in Chrome. If the Install button appears above, tap it. If not, tap the Chrome menu ⋮ and choose Install app or Add to Home screen.

Library features
Student NFC card scanning
Live book barcode scanning
Automatic book title lookup
Student-based book returns
Google Sheets transaction records

Open on your phone

Scan this QR code with an Android phone to open the Library app.
